# Лабораторная работа №5 — GDI+ (вариант 4: «Светофор»)

Приложение Windows Forms на C# (.NET 10) со средствами рисования GDI+ (`Graphics`, `Pen`, `Brush`, событие `Paint`):

- **Графический редактор** — линия, прямоугольник, эллипс, многоугольник, текст; выбор цвета и толщины линии, заливка.
- **Светофор** (индивидуальный вариант 4) — нарисованный через GDI+ светофор с ручным и автоматическим переключением сигналов.

## Требования

- Windows 10 / 11
- [.NET SDK 10.0](https://dotnet.microsoft.com/download) или новее (проверка: `dotnet --version`)
- Для работы в Visual Studio — версия с поддержкой `.slnx` (Visual Studio 2022 17.13+) и рабочая нагрузка «Разработка классических приложений .NET»

## Сборка и запуск из командной строки

Из папки репозитория:

```bash
dotnet build "lab5-c#.csproj"
dotnet run --project "lab5-c#.csproj"
```

Собранный файл лежит в `bin\Debug\net10.0-windows\lab5-c#.exe` — его можно запустить двойным щелчком.

Релизная сборка в папку `publish`:

```bash
dotnet publish "lab5-c#.csproj" -c Release -o publish
```

## Сборка и запуск в Visual Studio

1. Открыть `lab5-c#.slnx`.
2. Нажать **F5** (запуск с отладкой) или **Ctrl+F5** (без отладки).

## Как пользоваться

Главное окно содержит три кнопки: «Графический редактор», «Светофор (вариант 4)» и «Выход».

**Графический редактор**

- Инструмент выбирается кнопками сверху: «Линия», «Прямоугольник», «Эллипс», «Многоугольник», «Текст».
- Линия, прямоугольник, эллипс — зажать левую кнопку мыши на холсте и протянуть.
- Многоугольник — левой кнопкой ставить вершины, правой кнопкой (или двойным щелчком) завершить фигуру.
- Текст — ввести надпись в поле «Текст» и щёлкнуть по холсту.
- «Толщина» — толщина линии (1–20), цветные квадраты и кнопка «Другой...» — выбор цвета, «Заливка» — закрашивать фигуры, «Очистить» — стереть всё.

**Светофор**

- «Переключить сигнал» — ручное переключение (красный → зелёный → жёлтый).
- «Старт» / «Стоп» — автоматическое переключение по таймеру (красный и зелёный — 5 с, жёлтый — 2 с).
